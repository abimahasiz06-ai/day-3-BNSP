# Day 3 - BNSP Junior Web Developer

Repository ini berisi hasil pembelajaran hari ketiga pelatihan BNSP Junior Web Developer. Pada tahap ini, saya mempelajari dasar HTML dan CSS untuk membuat halaman web yang lebih terstruktur, menarik, dan responsif.

## 📚 Materi Pembelajaran

### 1. Membuat Curriculum Vitae (CV)

Pada materi ini, saya belajar membuat halaman CV pribadi menggunakan HTML dan CSS.

Hal-hal yang dipelajari:
- Membuat struktur halaman menggunakan HTML semantik.
- Menampilkan foto profil menggunakan tag `<img>`.
- Menampilkan informasi pribadi, pendidikan, keahlian, hobi, dan pengalaman organisasi.
- Menghubungkan file HTML dengan CSS.
- Mengatur warna, ukuran teks, jarak, dan tata letak halaman.
- Membuat desain CV menggunakan layout dua kolom.
- Menggunakan CSS Responsive agar tampilan menyesuaikan ukuran layar.
- Mengatur tampilan halaman ketika dicetak atau disimpan sebagai PDF.

### 2. Membuat Dashboard Inventaris

Pada materi ini, saya belajar membuat tampilan dashboard sederhana untuk pengelolaan inventaris barang.

Fitur tampilan yang dibuat:
- Header dan navigasi halaman.
- Kartu ringkasan jumlah barang.
- Informasi barang tersedia dan barang dipinjam.
- Tabel daftar barang.
- Tombol tambah barang.
- Label status barang menggunakan CSS.
- Layout responsif untuk perangkat desktop, tablet, dan ponsel.

Dashboard ini masih berupa tampilan antarmuka dan belum menggunakan database atau fungsi pengelolaan barang secara nyata.

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Membuat struktur dan konten halaman web.
- **CSS3:** Mengatur desain, warna, tipografi, tata letak, dan responsivitas.
- **Visual Studio Code:** Editor untuk menulis dan mengelola kode.
- **Live Server:** Menampilkan hasil pengembangan web langsung di browser.

## 🎯 Hasil Pembelajaran

Setelah menyelesaikan latihan ini, saya mempelajari cara:

1. Membuat halaman web menggunakan HTML.
2. Memisahkan struktur HTML dan desain CSS ke dalam file berbeda.
3. Menampilkan gambar pada halaman web.
4. Menggunakan Flexbox dan CSS Grid untuk mengatur tata letak.
5. Membuat tampilan web yang menyesuaikan ukuran layar.
6. Membuat CV digital dan dashboard inventaris sederhana.
7. Menggunakan media query untuk mengatur tampilan pada perangkat berbeda.
8. Mengatur tampilan halaman untuk kebutuhan cetak atau penyimpanan PDF.

## 💡 Kesimpulan

Melalui pembelajaran hari ketiga ini, saya mendapatkan pemahaman lebih lanjut mengenai penggunaan HTML dan CSS dalam pengembangan website. Saya juga belajar bahwa struktur kode yang rapi, pemisahan HTML dan CSS, serta desain responsif sangat penting untuk menghasilkan halaman web yang nyaman digunakan.

Latihan ini menjadi salah satu langkah saya dalam meningkatkan kemampuan di bidang pengembangan website sebagai Junior Web Developer.
